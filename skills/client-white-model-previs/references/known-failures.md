# 已出现的问题：执行中防复发

以下来自未通过样片的实际返修经验，不是已验证的通用自动匹配算法。

| 问题 | 根因/错误检查 | 承接约束与复查 |
|---|---|---|
| 人物前后与遮挡错 | 只比较深度轴或头中心，没有真实mesh投影/可见片段 | 源与render ID mask逐帧比对头/胸/手/袖可见面积，完整遮住/部分脸/重新出现分别标帧 |
| 前景头肩正确但远处身体从缝里露出 | 方块头身/肩臂有空隙，遮挡区仍强追旧手位置 | 一次静态修头身连接、贴身姿态；不可见手改合理可达姿态，仍是真3D实体 |
| 角色凭空出现/提前露出 | 用hide_render或生成时间凑 | 模型全镜真实存在；按源片实际画外和环境/人物遮挡决定入画，检查边界前后 |
| 行走像浮移 | 只有root运动；用ankle控制点Z判断脚已落地 | 真实shin/足底端面顶点对地面BVH，全帧支撑/摆动/换步，与源动作节奏复核 |
| 接地数值改善却蹲走、交叉腿、头下沉 | 固定错误推断足点，IK把残差用全身下修消化 | 保持可见头肩目标，隐藏足点先可达优化、小步距/合适节奏，实际看膝/重心，不能为低滑步而牺牲姿态 |
| 膝/肘大翻转 | IK平面/奇异点或手目标未随身体调整 | 稳定bend plane、合理相邻姿态；检查实际绑定mesh而非只检查控制骨，源快动作单独举证 |
| 把漂浮相位改NONE以过检查 | 标签替代几何事实 | NONE无豁免；腾空须source_verified_airborne+源证据，接地看真实端面和支撑面 |
| 场景跟着脚变地面高度 | 逐帧地面修补假支撑 | 地形是固定真实体积；推断地形与相机/身高一起复核，不漂移背景参照 |
| 为落地改相机导致背景不匹配 | 只按人物头脚fit，没静态held-out锚点 | 相机、主体、地形分别校准，独立静态点复核，不把 body-fit 候选当最终运镜 |
| 4K容器装低清放大图 | 只查MP4 width/height | 全部原生PNG真实像素+CRC/hash+实际render manifest，保存工程100%和64采样独立重开 |
| 确有PNG却最后一秒黑/闪/跳帧 | 只查文件数量/首帧 | 三MP4全解码+全播放、所有切点、片尾每帧及异常亮度变化实际看 |
| 对比没有声音或混入提示音 | 只处理视频流或随意加音频 | 从原片packet copy，实际payload/PTS比较和全音轨解码，听审不被JSON代替 |
| 工程在制作机开、团队机缺参考 | SaveAs自动remap、绝对路径、额外资源没包 | 保存到客户四文件同目录，//A.mp4或Pack，独立重开最终位置，ZIP成员hash回读 |
| 技术QA通过就宣称甲方通过 | 把数值、抽样、单帧、诊断误说完整视觉验收 | 明确工程/全媒体/逐帧视觉/客户回执四层；未完保持unverified/返修 |

不将这些个案坐标、动作曲线、未通过的解算轨迹、特定角色高度或本机渲染速度固化到所有任务。每条视频仍以真实参考和锁定规范为准。
